Chat, built into N.I.N.A.

The new plugin reads N.I.N.A. natively, renders guider and autofocus graphs, and exposes approved bot commands. Advanced API remains available for existing installations, but it is no longer required.

Simple local mode

N.I.N.A. starts a bundled Chatstronomy runtime and talks to it over a current-user-only pipe. Send notifications through a Discord webhook, run your own Discord application for slash commands, use a Matrix account on an HTTPS homeserver, or deliver to Discord and Matrix at the same time.

One hub, several observatories

Hosted mode pairs each plugin with the Chatstronomy hub. Every N.I.N.A. machine connects outbound over authenticated WSS, so one centralized bot can serve rigs on different systems without opening observatory ports or copying chat credentials to every computer. The complete integration is in the development build while the public hosted service is prepared separately.

Install a development build

  1. Open the latest successful plugin CI run on main.
  2. Download and extract chatstronomy-nina-package-smoke-test.
  3. Exit N.I.N.A. and extract the inner Chatstronomy.NINA.0.1.0.10.zip into %LOCALAPPDATA%\NINA\Plugins\3.0.0\Chatstronomy.
  4. Restart N.I.N.A. and open Plugins > Installed > Chatstronomy.

Development CI packages are for testing: the bundled Rust runtime is signed and release-pinned, while the development Chatstronomy.dll is unsigned. Official tagged packages sign and verify both binaries. Source and contributor registry instructions live in the plugin repository.

What lands in the channel

Enough to know how the night is going without opening a remote desktop.

Every sub, as it lands

New captures posted with their filter, exposure and target, on a cooldown you set so a fast sequence cannot flood the channel.

Autofocus and guiding

Focus runs arrive as a plotted curve, and guiding as a graph — the two things you actually want to squint at mid-session.

Live status

Sequence progress, mount state, meridian flip timing, and equipment readings, kept in one message that updates rather than repeating.

Several rigs at once

One process drives multiple telescopes concurrently, each with its own channel or room, under one bot identity.

Slash commands

Ask the rig what it is doing — and, if you turn it on, tell it what to do.

  • /status
  • /sequence
  • /target
  • /mount
  • /last-image
  • /autofocus
  • /guider
  • /events
  • /park
  • /unpark
  • /home
  • /cool
  • /change-filter
  • /abort-capture
  • /stop-sequence

Twenty-one in all; the read-only ones need no special permission.

Control is off until you enable it. Out of the box the bot posts; it does not act. Turning control on means a message typed in a chat channel moves real hardware, in the dark, with nobody standing next to it.

Commands that change anything are limited to Discord accounts you name, and the destructive ones ask for a confirmation first. Neither safeguard changes the underlying trade: your equipment's safety comes to rest on the security of a chat account. The terms spell out what to weigh before enabling it.

Choose your topology

On your own machine available now

Use the N.I.N.A. plugin's native Direct mode, or run the standalone backend against Advanced API. Bring a Discord webhook, your own Discord application, or a Matrix login. Nothing routes through anyone else's server; the backend can also run as a Windows service or Linux systemd unit.

Hosted hub development

The plugin can pair each N.I.N.A. installation with one centrally managed bot across machines. The observatory side stays outbound-only and reconnects without exposing N.I.N.A. or Advanced API to the internet. Public hosted access will follow its service-specific terms and privacy statement.

Open source, and honest about it

Chatstronomy is Apache-2.0 and developed in the open at github.com/theatrus/chatstronomy. It is unofficial software with no affiliation to N.I.N.A., Discord or Matrix. The name is bilingual — chat is the destination in English and the cat in French — and the logo says the same thing as a pipeline: space cat | chat.
