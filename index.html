N.I.N.A. 3.2+ on Windows · standalone Windows and Linux backend · Apache-2.0

Chat, built into N.I.N.A.

The plugin reads N.I.N.A. natively, renders guider and autofocus graphs, sends the event families you choose, and exposes approved bot commands. No N.I.N.A. web server or polling setup is required.

Recommended: Chatstronomy Hub

Pair the plugin with Chatstronomy Hub for the simplest setup. Each N.I.N.A. machine connects outbound over authenticated WSS, so one centralized Discord or Matrix bot can serve rigs on different systems without opening observatory ports or copying chat credentials to every computer.

Local Direct mode

Keep everything on the observatory computer with a Discord webhook, your own Discord application, or a Matrix account on an HTTPS homeserver. The plugin starts its signed, release-pinned Chatstronomy runtime in the background and supplies N.I.N.A. data directly.

Install from the N.I.N.A. plugin manager

  1. Open Plugins > Available, find Chatstronomy, install it, and restart N.I.N.A. once it appears in the official repository.
  2. For the current release from our development repository, open Options > General > Plugin Repositories, select +, and add https://raw.githubusercontent.com/theatrus/chatstronomy-nina-plugin/main/registry.
  3. Return to Plugins > Available, install Chatstronomy, and restart N.I.N.A.
  4. Open Chatstronomy Hub, create a pairing code, then choose Chatstronomy.com — hosted bot in the plugin and pair the rig.

N.I.N.A. supports more than one plugin repository, so adding the development repository does not replace the official one. It serves the current tagged package without a separate beta channel. Both the release-pinned runtime and Chatstronomy.dll are signed and verified before publication. See the plugin repository for current installation details.

What lands in the channel

Enough to know how the night is going without opening a remote desktop.

Every sub, as it lands

New captures posted as useful full-size previews with their filter, exposure and target, on a cooldown you set so a fast sequence cannot flood the channel.

Autofocus and guiding

Focus runs arrive as a plotted curve, and guiding as a graph — the two things you actually want to squint at mid-session.

Live status

Sequence and Target Scheduler targets, cooling and timed-wait progress, slews, centering results, mount state, meridian flips, equipment readings, N.I.N.A. notifications, and optional log levels.

Graphs, not just numbers

Slash commands

Ask the rig what it is doing — and, if you turn it on, tell it what to do.

  • /status
  • /sequence
  • /target
  • /mount
  • /last-image
  • /autofocus
  • /guider
  • /events
  • /park
  • /unpark
  • /home
  • /cool
  • /change-filter
  • /abort-capture
  • /stop-sequence

Twenty-one in all; the read-only ones need no special permission.

Control is off until you enable it. Out of the box the bot posts; it does not act. Turning control on means a message typed in a chat channel moves real hardware, in the dark, with nobody standing next to it.

Commands that change anything are limited to Discord accounts you name, and the destructive ones ask for a confirmation first. Neither safeguard changes the underlying trade: your equipment's safety comes to rest on the security of a chat account. The terms spell out what to weigh before enabling it.

Chatstronomy Hub recommended

Pair each N.I.N.A. installation with one centrally managed bot across machines. The observatory side stays outbound-only and reconnects without exposing N.I.N.A. to the internet. Open the Hub to begin.

On your own machine available now

Use the N.I.N.A. plugin's native Direct mode with a Discord webhook, your own Discord application, or a Matrix login. Nothing routes through anyone else's server, and the plugin manages the local runtime for you.

Open source, and honest about it

Chatstronomy is Apache-2.0 and developed in the open at github.com/theatrus/chatstronomy. It is unofficial software with no affiliation to N.I.N.A., Discord or Matrix. The name is bilingual — chat is the destination in English and the cat in French — and the logo says the same thing as a pipeline: space cat | chat.
