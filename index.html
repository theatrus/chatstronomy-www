From N.I.N.A. to Discord in three steps.

  1. Install

    In N.I.N.A., open Plugins > Available, install Chatstronomy, and restart. No extra repository needed.

  2. Choose what to share

    Open the plugin options and review events, images, logs, and location sharing.

  3. Pair with the Hub

    Open Chatstronomy Hub, get a pairing code, and enter it in the plugin. Connect your Discord channel in the Hub.

N.I.N.A. 3.2+ on Windows. Before pairing, read the Hub privacy policy and terms.

Looking for the development repository?

In Options > General > Plugin Repositories, select + and add:

https://raw.githubusercontent.com/theatrus/chatstronomy-nina-plugin/main/registry

This can sit alongside the official repository. Development repository guide

Check in. Or take control.

Use /chatstronomy in Discord to check status, request an image, or run a locally permitted command.

  • /chatstronomy status
  • /chatstronomy last-image
  • /chatstronomy autofocus
  • /chatstronomy center-rotate-target

Hardware commands need both the master switch and individual permission in N.I.N.A. Autofocus, filter changes, and target moves use matching triggers during an advanced sequence.

Command and trigger guide

One rig or several.

Pair each N.I.N.A. computer with the Hub and route its updates to your Discord channels. No observatory ports to open.

Prefer local? The plugin can run your own Discord bot, Discord webhook, or Matrix account. Matrix and webhooks support notifications, not slash commands.

Local setup guide

You choose what leaves N.I.N.A.

Disabled event categories are never sent to the Hub or local bot. Image, log, and location sharing have their own controls. Hub permissions cannot override local command permissions.
