This policy governs the privacy of self-hosted Chatstronomy.

This document was last updated on 16 August 2026.

The Chatstronomy application runs entirely on your local computer, does not communicate with our servers, and does not transmit any information about you or your equipment to us.

This covers only the self-hosted application. Chatstronomy Hub is a separately operated hosted service and is not covered by this statement. Do not rely on this page to understand what the Hub processes or retains; it requires a separate hosted-service privacy statement.

We do not collect personal data.

Nothing. There is no account, no telemetry, no analytics in the application, no crash reporting, and no licence check. In this version the program never contacts us, so there is no channel through which we could collect anything even if we wanted to.

Certain configuration and log files are stored on your local machine.

  • The application stores your configuration, which includes the Discord bot token or Matrix credentials you supply and the Chatstronomy settings within your N.I.N.A. profile.
  • The application maintains a small state file containing the identifiers of chat messages so the bot can edit a live status post instead of creating a new post each time.
  • The application generates log output, which is saved to the default locations managed by your operating system.

These are the only files stored locally. Removing the application and these files deletes all associated local data.

Data is transmitted directly to Discord or Matrix.

The application transmits the data you configure it to post, such as images, autofocus results, equipment status, and session progress. This data is sent directly from your machine to the configured chat service using your bot credentials, and it is governed by that service's privacy policy, such as the Discord Privacy Policy, or your Matrix homeserver's policy.

We do not have access to this data and cannot retrieve or delete it. If you need to remove information from a channel, you must manage it directly through your chat service.

Astronomical images often contain metadata headers that describe your equipment, capture time, and geographic location. Any user with access to the chat channel can view this metadata.

Slash commands are processed locally.

If you enable control features, the bot reads the Discord user ID of any user executing a slash command to verify them against your configured allow list. This verification process occurs locally on your machine and is not transmitted externally. The Terms of Service describe the security implications of enabling control features.

The marketing website collects standard web metrics.

The website at chatstronomy.com consists of static pages. The web server maintains standard access logs containing IP addresses to assist with site operations and security.

The site uses Google Analytics to measure visitor traffic and analyze page usage. It stores cookies in your browser and transmits details to Google, including your IP address, visited pages, and browser or device information. This data is processed by Google in accordance with the Google Privacy Policy, and we only access aggregated, anonymous reports.

The website does not collect analytics or metrics from the Chatstronomy application. The application does not connect to our servers. If you wish to opt out of web analytics, you can use a content blocker or the Google opt-out browser add-on, and the site will continue to function fully.

The software is not directed at children.

The Chatstronomy application is not directed at children, and we do not collect or store personal data.

You can contact the project via the issue tracker.

You can submit questions or reports through the project's issue tracker.
